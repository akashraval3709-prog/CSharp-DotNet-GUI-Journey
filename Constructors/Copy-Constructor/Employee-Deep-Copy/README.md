# 👨‍💼 Employee Deep Copy

A C# console application demonstrating how to implement a **Deep Copy** using a **Copy Constructor**. The program creates an independent copy of an `Employee` object along with its associated `Department` object.

## 📚 Features

- Create a Department object.
- Create an Employee object associated with a Department.
- Create a deep copy of an Employee using a Copy Constructor.
- Demonstrate independent object copying.
- Understand object state isolation.

## 📖 Concepts Covered

- Object-Oriented Programming (OOP)
- Constructors
- Copy Constructor
- Deep Copy
- Object Composition
- Reference Types
- Independent Object Copying
