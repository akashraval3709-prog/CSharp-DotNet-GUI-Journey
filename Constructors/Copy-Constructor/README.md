# 📋 Copy Constructor

This folder contains practical examples demonstrating the **Copy Constructor** concept in C#. Each project shows how to create a new object by copying the state of an existing object while maintaining object independence.

## 📚 Examples Included

- ✅ Product Copy
- ✅ Employee Deep Copy
- ✅ Player Deep Copy

## 📖 Concepts Covered

- Copy Constructor
- Object Copying
- Shallow Copy
- Deep Copy
- Object Composition
- Array Cloning
- Object State Isolation

## 🎯 Learning Outcome

- Understand how copy constructors work in C#.
- Learn the difference between shallow copy and deep copy.
- Practice copying primitive data, arrays, and custom objects.
- Build a solid foundation for object cloning and memory management.
