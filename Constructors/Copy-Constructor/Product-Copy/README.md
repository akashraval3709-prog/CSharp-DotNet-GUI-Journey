# 📋 Product Copy Constructor

A C# console application demonstrating the use of a **Copy Constructor** to create an independent copy of an object.

## 📚 Features

- Create a product object.
- Copy an existing object using a copy constructor.
- Modify the copied object's price.
- Verify that the original object remains unchanged.

## 📖 Concepts Covered

- Object-Oriented Programming (OOP)
- Constructors
- Copy Constructor
- Object Copying
- Reference vs Independent Objects
- Properties
