
# 🖥️ C# Windows Forms Journey

This folder contains my **C# .NET Windows Forms learning and practice projects**.
The goal is to understand GUI application development, Windows Forms controls, properties, events, and user interaction through small practical projects.

## 📚 Topics Covered

### 🪟 Windows Forms Basics

* Creating Windows Forms Applications
* Form Properties
* Form Title (`Form.Text`)
* Form Load Event
* Event Handling

### 🎛️ Windows Forms Controls

* Label
* Button
* TextBox
* ListBox
* CheckBox
* PictureBox
* MenuStrip
* ContextMenuStrip
* MessageBox

### ⚡ Events & Interaction

* Button Click Event
* TextBox TextChanged Event
* Form Load Event
* CheckBox CheckedChanged Event
* Mouse Events
* Context Menu Interaction

### 🛠️ Practical Projects

* **Editor Title Indicator**

  * Demonstrates dynamic Form Title changes
  * Shows `*` when text is modified
  * Restores the original title after Save

* **Calculator Application**

  * Basic arithmetic operations
  * Button-based input
  * Backspace and Clear functionality
  * Error handling

* **To-Do List Application**

  * Add tasks
  * Delete selected tasks
  * Clear tasks
  * Double-click task removal

* **Hobby Selector**

  * CheckBox selection
  * Display selected hobbies in ListBox
  * Enable/disable Submit button based on selection

* **ListBox Context Menu**

  * Right-click context menu
  * Edit selected item
  * Delete selected item
  * Update ListBox items

* **MDI Image Viewer**

  * MDI Parent and Child Forms
  * Open image using `OpenFileDialog`
  * Display images using `PictureBox`
  * Zoom In / Zoom Out
  * Reset image size
  * Close and Exit menu operations
