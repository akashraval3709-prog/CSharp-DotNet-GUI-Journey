# 🐶 Method Overriding - Animal Sound Demo

This C# console application demonstrates **Method Overriding** using inheritance. A base class `Animal` contains a virtual method `MakeSound()`, which is overridden by the derived classes `Dog` and `Cat` to provide their own implementations.

## 📄 File

```text
Program.cs
```

## 📚 Concepts Used

- Classes & Objects
- Inheritance
- Virtual Method
- Method Overriding
- Runtime Polymorphism
- Base Class Reference

## ▶️ Sample Output

```text
=== Animal Sounds ===

Dog says: Woof Woof!
Cat says: Meow Meow!
```

## 🎯 Learning Outcome

- Understand how to declare a virtual method.
- Learn how derived classes override base class methods.
- Demonstrate runtime polymorphism using base class references.
