# ✅ Hobby Selector

A Windows Forms application that allows users to select multiple hobbies using **CheckBox** controls and display the selected hobbies in a **ListBox**.

## 📂 Files

```text
Program.cs
Form1.cs
Form1.Designer.cs
Form1.resx
README.md
Screenshot.png
```

## ✨ Features

- Select multiple hobbies using CheckBoxes.
- Enable the Submit button only when at least one hobby is selected.
- Display selected hobbies in a ListBox.
- Simple and interactive Windows Forms interface.

## 📚 Concepts Used

- Windows Forms
- CheckBox
- ListBox
- Button
- Label
- Event Handling
- CheckedChanged Event
- Form Load Event

## ▶️ Sample Workflow

```text
Application Starts
        │
        ▼
Select One or More Hobbies
        │
        ▼
Submit Button Enabled
        │
        ▼
Click Submit
        │
        ▼
Selected Hobbies Displayed in ListBox
```
