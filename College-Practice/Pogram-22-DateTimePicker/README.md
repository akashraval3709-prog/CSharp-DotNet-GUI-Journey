# 📅 DateTimePicker Date Selector

A Windows Forms application that demonstrates the use of the **DateTimePicker** control to select a date and display the selected date dynamically in a Label.

## 📄 Files

```text
Program.cs
Form1.cs
Form1.Designer.cs
Form1.resx
README.md
Screenshot.png
```

## ✨ Features

* Select a date using the DateTimePicker control.
* Display the selected date dynamically in a Label.
* Update the Label when the selected date changes.
* Handle the DateTimePicker `ValueChanged` event.
* Provide a simple and user-friendly Windows Forms interface.

## ⚙️ Working

```text
Select Date
     ↓
DateTimePicker Value Changes
     ↓
ValueChanged Event
     ↓
Get Selected Date
     ↓
Display Date in Label
```

## 🖥️ Example Output

```text
Selected Date 14-08-2026
```
