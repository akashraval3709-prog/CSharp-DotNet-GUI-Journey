# 🖼️ MDI Image Viewer

A Windows Forms MDI (Multiple Document Interface) application that allows users to open image files using an **Open File Dialog** and display them in child windows. Each child window provides controls to zoom in, zoom out, and reset the image size.

## 📄 Files

```text
Program.cs
Form1.cs
Form1.Designer.cs
Form1.resx
picture.cs
picture.Designer.cs
picture.resx
```

## ✨ Features

- Open image files (.jpg, .png)
- Display images inside MDI child forms
- Zoom In image
- Zoom Out image
- Reset image to original size
- Close active child window
- Exit the application

## 📚 Concepts Used

- Windows Forms
- MDI Parent & Child Forms
- MenuStrip
- OpenFileDialog
- PictureBox
- Button Controls
- Event Handling
- Image Processing

## ▶️ Sample Workflow

```text
Application Starts
        │
        ▼

        │
        ▼

        │
        ▼

        ▼

```
