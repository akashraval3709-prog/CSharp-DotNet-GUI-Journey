# ✅ To-Do List

A Windows Forms application that allows users to manage daily tasks through an interactive **To-Do List**. Users can add, delete, clear, and quickly remove tasks using mouse interactions.

## 📂 Files

```text
Program.cs
Form1.cs
Form1.Designer.cs
Form1.resx
README.md
Screenshot.png
```

## ✨ Features

- Add new tasks.
- Delete selected tasks.
- Clear all tasks.
- Double-click a task to remove it instantly.
- Input validation using MessageBox.
- User-friendly Windows Forms interface.

## 📚 Concepts Used

- Windows Forms
- ListBox
- TextBox
- Button
- MessageBox
- Event Handling
- MouseDoubleClick Event
- ListBox Collection
