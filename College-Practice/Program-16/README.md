# 🧮 Calculator App

A Windows Forms application that performs basic arithmetic calculations using button controls and evaluates mathematical expressions entered by the user.

## 📄 Files

```text
Program.cs
Form1.cs
Form1.Designer.cs
Form1.resx
```

## ✨ Features

- Enter numbers using calculator buttons.
- Perform addition, subtraction, multiplication, and division.
- Evaluate expressions using the **Equal (=)** button.
- Delete the last entered character using the **Back** button.
- Clear the entire display using the **Clear** button.
- Display **ERROR** for invalid expressions.
- Automatically restore normal input after an error.

## 📚 Concepts Used

- Windows Forms
- Button Click Events
- TextBox
- DataTable.Compute()
- Exception Handling
- String Manipulation
- GUI Programming
