# 👤 Gender & Marital Status Selector

A Windows Forms application that allows the user to select their **gender** and **marital status** using RadioButtons. After both selections are made, the application displays the selected information dynamically in a Label.

## 📄 Files

```text
Program.cs
Form1.cs
Form1.Designer.cs
Form1.resx
README.md
Screenshot.png
```

## ✨ Features

* Select gender using RadioButtons.

  * Male
  * Female
* Select marital status using RadioButtons.

  * Married
  * Unmarried
* Display the selected gender and marital status dynamically.
* Clear the message when either selection is incomplete.
* Update the result using `CheckedChanged` events.
* Provide a simple and user-friendly Windows Forms interface.

## ⚙️ Working

```text
Select Gender
      ↓
Select Marital Status
      ↓
Check Both Selections
      ↓
Set Gender & Marital Status
      ↓
Display Result in Label
```
