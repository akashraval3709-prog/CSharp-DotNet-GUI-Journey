# 📋 ListBox Context Menu - Edit & Delete

A Windows Forms application demonstrating how to manage items in a `ListBox` using a right-click context menu.

The user can right-click a country item and perform **Edit** or **Delete** operations.

## 📄 Files

```text
Program.cs
Form1.cs
Form1.Designer.cs

README.md
Screenshot.png
```

## ✨ Features

- Display countries in a ListBox
- Right-click on a ListBox item
- Delete selected country
- Edit selected country
- Update edited country
- Show and hide edit controls dynamically

## 📚 Concepts Used

- Windows Forms
- ListBox
- ContextMenuStrip
- MenuStrip Items
- Right Mouse Button Event
- SelectedIndex
- SelectedItem
- ListBox Items
- Insert and Remove operations
- Button Click Event
- Event Handling

## ▶️ Workflow

```text
Select Country
      ↓
Right Click
      ↓
┌───────────────┐
│ Edit          │
│ Delete        │
└───────────────┘
      ↓
Edit → Update
Delete → Remove Item
```

## 🎯 Learning Outcome

- Learn how to use `ContextMenuStrip` with a ListBox.
- Understand selected item operations.
- Practice adding edit and delete functionality.
- Learn to handle right-click events in Windows Forms.
